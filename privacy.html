Privacy policy

Prepared 2 November 2026

These tools use the owner's authorised Drive files and metadata for requested operations. The CLI stores credentials locally. Planned assistant features also use Gmail messages and Calendar events for actions, summaries and reminders.

Relevant content may be processed by Anthropic's API and sent to the owner's private Telegram chat. The assistant will store credentials in Infisical, and conversations and task data on the owner's server and backups until deleted. Google data is not sold or used for advertising.

Revoke access through Google Account connections; delete stored data and backups separately. Provider-held data follows each provider's policies.

This site has no analytics. GitHub Pages records visitor IP addresses; see GitHub's privacy statement.
